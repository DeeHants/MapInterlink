# MapInterlink

This is a simple Chrome extension that shows map coordinates, and links to different map sites.

Install (developer mode):

1. Open Chrome and go to `chrome://extensions`.
2. Enable "Developer mode" (top-right).
3. Click "Load unpacked" and select the `extension` folder:

   MapInterlink\extension

Usage: click the extension action icon to open the popup; it will display the current tab's URL.
